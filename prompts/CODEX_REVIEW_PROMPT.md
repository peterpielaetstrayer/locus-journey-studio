# Codex Independent Review Prompt

Review the existing LOCUS Journey Studio implementation. Do not modify code during the first pass.

Read `AGENTS.md`, `.cursor/rules/`, all product and architecture docs, acceptance criteria, and visual direction.

Evaluate:

1. product fidelity
2. architecture
3. type safety
4. adaptation correctness
5. learner-mode restraint
6. Creator/Orchestrator distinction
7. human override
8. persistence
9. accessibility
10. responsive behavior
11. truthful labeling
12. acceptance coverage
13. privacy/security appropriate to prototype
14. dashboard drift
15. unnecessary complexity

Output:

- executive assessment
- critical defects
- product gaps
- engineering risks
- accessibility issues
- learning-design violations
- safety/trust violations
- acceptance matrix
- repair sequence

For each issue include file/route, behavior, why it matters, fix, severity.

Wait for approval before implementing.
