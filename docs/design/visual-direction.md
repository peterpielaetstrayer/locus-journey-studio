# Visual Direction — LOCUS Journey Studio

## Design thesis

LOCUS uses technology to reintroduce the learner to the world. The interface should direct attention, support inquiry, and recede.

## Qualities

Wonder, quiet confidence, curiosity, seriousness, warmth, precision, and mystery without manipulation.

## Mode direction

### Learner

- immersive image-led surfaces
- minimal text
- one central question
- prominent capture
- fogged map used sparingly
- quiet-attention choices
- warm artifact transition

### Creator

- workspace surfaces
- route and content visible together
- strong hierarchy
- structured learning fields
- preview dock
- evidence and safety visible

### Orchestrator

- learner cards
- recent evidence
- recommendation + reason
- human override
- meaningful alerts only

### Reviewer

- sober quality-control environment
- checklist and unresolved issues
- explicit status

## Typography

Interface: Geist, Inter, or equivalent.  
Artifact accent: Source Serif 4, Fraunces, or equivalent.

## Motion

Use subtle route reveals, card assembly, state transitions, and map fog clearing. Respect reduced motion. No constant animation.

## Imagery

Local assets for cypress wetland, trail, knees, wet/dry comparison, overlook, and shoreline. Always add meaningful alt text.

## Artifact

The Micro-Landscape Systems Card should feel printable and durable, not like a social achievement card.
