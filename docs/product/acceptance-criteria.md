# Acceptance Criteria — LOCUS Journey Studio v0.1

## Global

- [ ] Application runs locally without authentication.
- [ ] Production build, type checking, and linting pass.
- [ ] Creator, Learner, Orchestrator, and Reviewer modes are accessible.
- [ ] Role switching preserves state.
- [ ] Demo reset restores initial state.
- [ ] Mobile and desktop layouts work.
- [ ] No Lorem Ipsum remains.
- [ ] Simulated AI and mock analytics are labeled.
- [ ] Journey status is Field-Test Draft.
- [ ] No implication of legal, park, insurance, or youth-program approval.

## Demo Gateway

- [ ] Headline and description.
- [ ] Create, Experience, Orchestrate, Review entry points.
- [ ] OWLL → LOCUS → Field Notes relationship.
- [ ] Guided demo entry.

## Creator

- [ ] Journey Library with canonical and future journeys.
- [ ] Water Writes the Landscape opens.
- [ ] Overview locally editable.
- [ ] Route displays eight stops.
- [ ] Cypress-Knee Mystery exposes full stop anatomy.
- [ ] Four adaptive branches.
- [ ] Learner preview changes for Maya, Eli, Jordan.
- [ ] Safety/accessibility visible.
- [ ] Review pipeline with unresolved issues.
- [ ] Creator economy marked future/nonfunctional.

## Learner

- [ ] Start as Maya.
- [ ] Enter baseline explanation and confidence.
- [ ] Fogged map with revealed/hidden content.
- [ ] Water Fingerprints minimal prompt.
- [ ] Save Field Note.
- [ ] Capture observation, inference, evidence, confidence, question.
- [ ] Deterministic follow-up.
- [ ] Comparison challenge.
- [ ] Editable systems map.
- [ ] Exit claim.
- [ ] Baseline vs revised view.
- [ ] Artifact assembly.
- [ ] Idea Returns asks retrieval before notes.
- [ ] Shoreline transfer prompt.

## Orchestrator

- [ ] Maya, Eli, Jordan with distinct states.
- [ ] Learner Detail.
- [ ] Recommendation includes reason.
- [ ] Accept, modify, ignore, replace.
- [ ] Human override persists.
- [ ] Intervention appears for learner.
- [ ] Artifact review rubric.

## Reviewer

- [ ] Learning, factual, safety, accessibility, field test, maintenance.
- [ ] Unresolved issues visible.
- [ ] Approval status explicit.
- [ ] Cannot imply public youth approval.

## Adaptation

- [ ] High confidence + weak evidence.
- [ ] Low confidence + strong observations.
- [ ] Eli inactivity.
- [ ] Jordan stepwise support.
- [ ] Maya advanced extension.
- [ ] Unsafe action refusal.
- [ ] Mentor override.

## Persistence

- [ ] Selected role.
- [ ] Field Notes.
- [ ] Intervention.
- [ ] Systems Map.
- [ ] Artifact.
- [ ] Demo reset.

## Accessibility

- [ ] Keyboard navigation.
- [ ] Visible focus.
- [ ] Alt text.
- [ ] No color-only status.
- [ ] Reduced motion.
- [ ] ~44px touch targets.
- [ ] Map list alternative.
- [ ] Text equivalent for audio.

## Visual quality

- [ ] Learner quieter than Creator.
- [ ] Not a generic admin dashboard.
- [ ] Outdoor-legible typography.
- [ ] Coherent design tokens.
- [ ] No excessive glassmorphism/neon.
- [ ] One primary task per Field screen.
- [ ] Artifact feels portfolio-worthy.

## Completion report

The build agent must report completed, partial, omitted, known issues, commands run, test results, and build status. It must not claim production readiness.
